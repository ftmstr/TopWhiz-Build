## Structure and possible usage

- `logos/`: full/logo artwork for brand identity concepts, marketing review and headers.
- `monograms/`: TW marks suitable for compact brand placement after visual QA.
- `app-icons/`: application icon candidates, not yet converted to platform store assets.

**Do not imply a final brand direction** based on the file naming. The variants include Siyah-Altin, Mavi-Teknoloji and Kirmizi-Sari color concepts.

## Asset governance

1. Maintain original filenames for reproducibility.
2. Record any newly derived favicon, PNG, SVG or store-app icon separately from the original source and document the processing steps.
3. Before shipping, visually verify actual resolution, transparency, legibility at small sizes, color profile and contrast; filename suffixes alone are not proof of rendered pixel dimensions.
4. Keep the original Drive assets unchanged.
5. This public code repository is AGPL-3.0, but that does not establish registered trademark rights. Clarify the separate usage/licensing policy for brand assets before external reuse; see legal gate issue #2.
6. Do not publish a commercial-branded release until TOPWHIZ/TOPWIZ similarity has been properly examined. Uploading these drafts to GitHub is not a clearance or production release.
