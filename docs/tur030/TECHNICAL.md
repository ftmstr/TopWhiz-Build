# TUR030 technical — real disposable PG16 CAS race and COMMIT transport interruption
Parent TUR029 Draft PR #33 exact HEAD 6e6e3e96490fe4c55d8411c653bd861ce1af3f4a. No production code or dependency changes.
A new PostgreSQL 16 integration test opens two independent password-authenticated writer logins. Two concurrent generation-1 compare-and-swap revocations race: exactly one wins, the other returns zero rows; stale generation-1 resurrection is denied. An out-of-band privileged admin then rewinds generation and rights, demonstrating an OWNER/SUPERUSER threat rather than claiming monotonicity against privileged actors.
A separate real transaction sends COMMIT then immediately destroys the client's TCP transport. Outcome may be committed or absent; a separate durable readback determines observed state. This is a genuine transport interruption but does NOT guarantee the server received COMMIT, and cannot prove exactly-once recovery, receiver ACK or last network byte. Unlike TUR029's known post-COMMIT discarded ACK, this covers uncertain server receipt. PostgreSQL 16 CI is required to prove these tests ran. Inherited TUR019/021/029 PG16 tests run again.
