# TOPWHIZ TUR118 — Indirect function EXECUTE via group membership / SET ROLE (NO-GO)

Function EXECUTE is checked against **effective privileges**, including inherited group role grants, not only direct GRANT entries for a particular SQL login. After a SECURITY DEFINER function ownership transfer, PostgreSQL rewrites ACL grantor metadata (TUR117) while preserving group grantee EXECUTE. A direct `REVOKE EXECUTE FROM broker` is not an authorization cutoff when broker still inherits EXECUTE via executor_group. Separate `REVOKE executor_group FROM broker` after COMMIT closes that path. Regranting membership `INHERIT FALSE, SET TRUE` still permits a broker with the same LOGIN session to `SET ROLE executor_group` and invoke the elevated cancellation function; INHERIT FALSE by itself is not a complete protection. `INHERIT FALSE, SET FALSE` spectators cannot call or impersonate group. Runtime negative is real only after disposable PG16 CI physically succeeds.
