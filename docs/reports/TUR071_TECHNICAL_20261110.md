## Precise implementation
The original `services/prices-worker/src/cms/media-handler.mjs` accepts a strictly **optional** `abortSignal` argument in the injection map. The deployed Worker caller and real Next.js route do not pass this opt-in: no production cancellation guarantee is claimed. With a signal, `readWithAbort` listens for abort during an actual pending `ReadableStreamDefaultReader.read`, requests upstream `reader.cancel()`, returns fail-closed 503 to a still-attached HTTP client (or no reply to already-closed socket), and does not wait indefinitely for a stalled asynchronous source pull. Abort checks guard pre/post initial media lookup, R2-like bucket read, SHA-256 validation, final guardian re-read and response construction. Existing streamed PNG/JPEG/WebP validation, length cap, cache no-store and original handler remain the same without a signal.

The independent `guardian-approval-contract.mjs` now optionally takes the same signal and checks it before/after each asynchronous media and guardian read; it forwards signal to injected read functions. This is a **cooperative cancellation protocol**, not proof that PostgreSQL backend execution is actually cancelled after a SQL query is sent. Separate IAM, owner and SECURITY DEFINER privilege tests remain inherited.

## Novel live-local acceptance
New CI-only disposable PostgreSQL16 integration test uses actual Node loopback TCP, original CMS media handler, original SHA-256 synthetic PNG factory and four distinct non-superuser password LOGINs (media reader/owner and independently owned guardian reader/owner). A real TCP client drops the connection before headers while fictional R2-like stream is blocked after its first half. The test-only Node HTTP server bridges `ServerResponse.close` to `AbortController.abort`. The handler should terminate without waiting for the second stream half, invoke source cancellation, avoid the final guardian SQL, and send zero bytes to the disconnected client. A separate guardian-owner SQL session COMMITs revocation and a fresh HTTP request returns 404/0. The earlier TUR068 negative test is retained **unchanged** with no abortSignal: it consumes all 8,273 fictional bytes after socket close; TUR069 proves 25 bytes already delivered before revocation cannot be recalled.
