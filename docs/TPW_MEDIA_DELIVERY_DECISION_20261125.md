## Decision
No feasible strict receiver-last-byte guarantee established for arbitrary public HTTP readers. A sender cannot recall buffered or already downloaded bytes; Durable Object output gates wait for storage writes but do not prove receiver byte delivery; R2 I/O can interleave. No redefinition of revocation effective time without independent legal and security approval. Keep full media off. Prefer no third-party media in future first-scope review, not release permission.
## Conditional architecture for separately authorized prototype
Private R2 only (no r2.dev, public custom domain, presigned URLs or independent image transforms); per-asset DO with durable authority generation, OPEN / REVOKING / QUARANTINED / REVOKED, one serializable admission and withdrawal command path; independent rights-admin IAM, monotonic commands, idempotent receipts, content hash pinned. Route all requests including HEAD/range/conditional and variants through same authority; deny unreviewed paths and cache bypass. Do not treat lease expiry, stream close, cancel, timeout, connection loss, JS enqueue or worker response as receiver ACK. Abort active reads on withdrawal, deny new admissions immediately, keep uncertain permits quarantined; do not automatically mark revocation completed. Legal withdrawal time remains original, not delayed to make tests pass. Purge legacy cache inventory after authorized isolated testing; no-store only prevents some new caching, purge is not downloaded-copy recall. Public receiver can't be trusted to attest. Proposed restricted authenticated receiver protocol only if independent reviewer accepts changed threat model; still not existing Issue #22 zero leak PASS. No actual DO/R2 provisioning.
PG cancellation: separate per-tenant dedicated connection ownership, prohibit pool reuse until all cancellation/transaction outcomes reconciled, quarantine uncertain connections, no shared arbitrary pg_cancel_backend or TUR150 SECURITY DEFINER. Actual production runtime, role boundaries and physical receiver tests needed.
