# TOPWHIZ web design preview

TUR002 is a responsive, Turkish-language Next.js App Router prototype. All catalog entries and comparison values are synthetic demo content. The selected primary logo is the original \`TopWhiz_Logo_02_KirmiziSariMavi.png\` inside \`public/brand/\`.

From repository root:

\`\`\`sh
corepack enable
pnpm install --no-frozen-lockfile
pnpm dev
\`\`\`

Local URL: http://localhost:3000 (not a deployed service).

Check: \`pnpm test\`, \`pnpm typecheck\`, \`pnpm build\`.

**Important:** No production deployment, no indexing, no actual price/benchmark claims. Trademark clearance and external asset usage rights remain pending. Add and lock a dependency lockfile before accepting release readiness.
